# AI Codebase Assistant

Production-grade AI system for semantic search and contextual Q&A across large codebases.

---

## 🧠 Overview

This project enables developers to query large repositories using natural language.

It indexes source code, generates embeddings, and retrieves relevant context to provide accurate, code-aware responses using LLMs.

---

## 🚀 Features

- Semantic search across large codebases
- Context-aware responses using retrieval-augmented generation (RAG)
- Code-aware indexing (functions/classes instead of raw text)
- Multi-file context retrieval
- Scalable indexing pipeline
